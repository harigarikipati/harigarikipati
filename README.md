## 🧭 How I Work

- **Start with the decision, not the data.** Every report answers a question someone needs to act on.
- **One definition per metric.** A KPI means the same thing in every report, or it means nothing.
- **Model first, visuals second.** A good semantic model makes every dashboard faster, simpler, and trustworthy.
- **Adoption is the measure of success.** A dashboard nobody opens is a failed project.
